# 04 · 编译规则：括号 → 镜头

这是全片质量的分水岭。**选错镜头，后面渲得再漂亮也是配图。**

---

## 先记住五条

1. **配图不是讲解。** 把画面换到别的文案里照样成立 → 它是配图，不是讲解。
2. **一镜一件事。** 一屏只让观众看一件事。
3. **屏上的东西观众得认得。** 抽象词（认知负荷、双通道）没有形象，要么换成具体的东西，要么这一镜不配图。
4. **动词要真的发生。** 说「减半」就真少一半；说「跳过这一步」，那一步就在画面上被划掉。
5. **该停就停。** 提问、命名、下结论、引出处——这四类句子不配新画面。

> 一句自检：**这句话里有东西在动吗？** 没有就别画。

---

## 决策顺序

对每个括号 / 每句话，从上往下问，第一个成立的就是答案：

1. 这句话里有东西在动吗？ → 没有：用 `quote` 或 `title`，或者并到下一镜
2. 是一个数 / 一个比例 / 一个年份吗？ → `stat` 或 `bars`
3. 是「两种东西不一样」吗？ → `compare`
4. 是「几个步骤 / 省掉了哪一步」吗？ → `flow`
5. 是「一堆并列的要点」吗？ → `bullets`
6. 提到了一个人吗？ → `person`
7. 提到了一个公司 / 产品吗？ → `brand`
8. 有现成的图 / 视频吗？ → `image` / `video`
9. 都不是 → 说明这句没想清楚，**别硬画**：用 `quote` 上字，或者并到下一镜

---

## 常见写法对照

| 括号里通常这么写 | 用哪个 |
|---|---|
| 片名卡 / 开场 / 标题浮现 | `title` |
| 三条原因 / 几个要点 / 罗列 | `bullets` |
| 大数字 / 两倍 / 90% / 翻一倍 | `stat` |
| 金句 / 引用 / 他说 | `quote` |
| 一张图 / 截图 / 照片 | `image` |
| 放一段视频 / 片段 / B-roll | `video` |
| 左右对比 / 以前 vs 现在 / 误解和真相 | `compare` |
| 流程 / 三步 / A→B→C / 省掉了哪一步 | `flow` |
| 柱状图 / 数据对比 / 占比 | `bars` |
| 代码 / 关键那几行 | `code` |
| 某个人 / 他的照片 | `person` |
| 某个公司 / 品牌 | `brand` |

---

## 反例：括号写了抽象词

> 口播：「大脑的工作记忆容量有限。」
> 括号：（画面：展示工作记忆的容量限制）← **画不出来**

三种解法，选一个：

1. **换成具体的东西**：`compare` 左边「一次只能想 3 件事」，右边「画面帮你挂住 3 件」
2. **改成不配图**：这句是结论，用 `quote` 上大字，让观众读
3. **拆镜**：这句不配，把画面留给下一句具体的例子

**不要**为了这一句硬造一个抽象图形。

---

## 没写括号时的自动配图

| 稿子里提到 | 用 | 说明 |
|---|---|---|
| 一个**人** | `person` | 取照片 → 亲眼看 → 是本人就用；确认不了用文字卡 |
| 一个**公司 / 产品** | `brand` | 文字 wordmark，不抓 logo |
| 「三点」「几个方面」 | `bullets` | 说了几点放几条 |
| 数字 / 年份 / 比例 | `stat` | 数字要真 |
| 两种东西的差异 | `compare` | |
| 先后 / 流程 / 因果 | `flow` | 3–5 步 |
| 用户给了素材 | `image` / `video` | 优先用他的 |
| 都不成立 | `quote` / `title` | 上字，不硬画 |

**硬约束：宁可没有图，也不要错图。**

---

## 节奏

| 症状 | 病因 | 药 |
|---|---|---|
| 看着像 PPT | 全是 `bullets` 和 `title` | 中间插 `compare` / `flow` / `bars` / `person` |
| 看着很忙但没记住 | 一镜塞了三件事 | 拆 |
| 抽象、听不懂 | 抽象词硬配抽象图 | 换具体形象，或只上字 |
| 节奏平 | 每镜一样长一样重 | 长短交替：短镜 3 秒，重点镜 8 秒 |

**镜头搭配**：一段 5 分钟以上的片子，`bullets` 和 `title` 加起来别超过 1/3，其余用 `compare` / `flow` / `person` / `brand` / `image` 撑。
