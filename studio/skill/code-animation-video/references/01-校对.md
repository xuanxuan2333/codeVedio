# 01 · 校对

用户丢过来的稿子，可能是语音转文字、带一堆口头禅、有错别字。
**默认策略：逐字保留。** 改得越多，片子越不像他本人在讲。

---

## 只改三类

| 类型 | 判定标准 | 改法 |
|---|---|---|
| **严重语病** | 读不通、有歧义、指代不清，观众会卡住 | 最小改动，修到能读通就停 |
| **错别字 / 识别错** | 明显打错字；语音转文字的同音字 | 直接改对 |
| **事实错误** | 与公认事实冲突，或与可查来源不符 | 查证后改，**并在交付时单独列出** |

「严重」是关键词。**读得通的小毛病不算语病。**「他今天来了然后我们就走了」没有逗号——那是标点问题，补逗号即可，不算语病。

---

## 明确不改（这些是风格，不是错误）

- 口头禅：「那个」「就是说」「诶」「然后呢」「你懂吧」「对吧」
- 口语化：「钱烧完了就没人管了」「这玩意儿」「整一个」
- 重复、绕：「然后呢然后呢」「就是说就是说」
- 语序、断句习惯、句子长短（40 个字一句也照留）
- 语气词、个人腔调、方言用法
- **你觉得「不够专业」「不够高级」的表达**

> 判断口诀：**如果改动让句子"更好"但意思没变，那就是不该改。**

---

## 三个例外（可以做）

### ① 补标点

TTS 靠标点断句。一段话一个标点都没有，会念成一口气。

```
原文：今天聊聊AI的方法它其实分三步
改写：今天聊聊 AI 的方法。它其实分三步。
```
**一个字没动**，只是断开。

### ② 英文 / 数字排版统一

`AI` / `A.I.`、`2012` / `二零一二`——统一成一种，方便 TTS 念对、字幕好看。

注意：TTS 念英文词可能口音怪。必要时在词后加逗号让它停顿（「transform，这个属性」），但**不要改词**。

### ③ 事实错误

查证 → 改 → 在交付里单独说：

> 事实修正：原稿说「2012 年 AlexNet 发布」，实际是 2012 年 10 月 NIPS 上亮相，已改为「2012 年」。

**不许默默改。** 可能是他故意说的，也可能是你查错了。

---

## 拿不准的时候

| 情况 | 做法 |
|---|---|
| 改不改都行 | **不改** |
| 事实可疑但查不到 | 保留原文，交付时标「这句可能需要核实」 |
| 一句话完全画不出来 | 不要改稿，改用 `quote` / `title` 上字（见 04） |
| 一句话太长 | 不要改稿，拆成两个镜头（见 02） |

---

## 交付话术

**改动了：**

```
校对：3 处
1. 「以经」→「已经」（错别字）
2. 「人工智能这个'词'」→ 直角引号（排版）
3. 「三次寒冬」→「几次寒冬」（主流说法是两次寒冬，改成模糊表述更稳）
口头禅「诶」「那个」全部保留。
```

**没改动：**

```
校对：未改动（原文没有语病和错别字）。
```

**只改了标点：**

```
校对：只补了逗号和句号（原文一段话没有标点，TTS 会念成一句）。
一个字没动。
```

---

## 一条自检

改完之后，把改后的稿子和原文并排放，问自己：
**这两段读起来，是同一个人在说话吗？**

答"不太像"，就是改多了，退回去。
