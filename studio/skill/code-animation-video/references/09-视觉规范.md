# 09 · 视觉规范（配色 / 图片 / 层级）

一份片子的"高级感"九成来自这三件事：**配色克制、图片统一、层级分明。**
技术实现都在 `kit/style.css` 的 `:root` 和 `.light` 里，改主题只改那里。

---

## 一、配色

### 两套主题，二选一

| | 深色 | 浅色（纸感） |
|---|---|---|
| 底 | `#0b0d12` | `#f5f6f8`（**不用纯白**，纯白发飘） |
| 主文字 | `#e6edf3` | `#111418` |
| 次要 | `#8b949e` | `#5a6572` |
| 线 | `#242c39` | `#e2e6ee` |
| 强调 | `#58a6ff` | `#2563eb` |
| 第二强调 | `#bc8cff` | `#7c3aed` |

`meta.theme: "light" | "dark"`，运行时给 `<body>` 挂 class，其余全走变量。

### 三条铁律

1. **三个颜色，不要更多。** 底 / 主 / 强调。最多再加一个"代价色"（橙 `#E4572E`），
   全片只能表达一件事（危险、代价、反例）。
2. **强调色全片只表达一件事。** 蓝色到处用，观众就不知道蓝色代表什么。
3. **对比度优先于好看。** 白底上的蓝字、灰底上的灰字，先保证能读。

### 渐变：只在深色底上用

```css
/* ❌ 错：从白色开始渐变，浅色底上白字直接消失 */
background: linear-gradient(100deg, #ffffff 12%, var(--accent) 62%);

/* ✅ 对：从主题前景色开始 */
background: linear-gradient(100deg, var(--fg) 8%, var(--accent) 58%, var(--accent2) 96%);
```

**巨字、标题的渐变，起点必须是 `var(--fg)`**，不能写死白色。
（这条是踩过的坑：白→蓝渐变叠在白底上，前半截是隐形的。）

## 二、图片

### 来源优先级

| 优先级 | 来源 | 用在哪 | 命令 |
|---|---|---|---|
| 1 | **用户给的素材** | 括号点名的图/视频 | 放 `assets/` |
| 2 | **实拍照片**（Wikimedia Commons） | 真实人物、真实场景、真实物件 | `fetch-media.mjs` / `fetch-batch.mjs` |
| 3 | **AI 生成插画** | 抽象概念、比喻、没有实物可拍的东西 | `gen-image.mjs` |

**默认走实拍。** 只有"这个东西根本拍不出来"（权力的边界、代理人、把人群拧成一股绳）才生成。

### 铁律：宁可没有图，不要错图

- 照片下载后**必须亲眼看一遍**（实测搜「prison cell」会返回细胞周期图，搜「Adolf Hitler portrait」会返回婴儿照）
- 真实人物、品牌、新闻现场**不许 AI 生成**——幻觉细节会翻车且误导
- 用了 Commons 的图，`credit` 字段必须填（作者 + 协议）

### 一个镜头放几张

**一句一张图会显得死板。** `image` 支持 `srcs` 数组，按句长自动排（每张约 2.4 秒）：

| 镜头时长 | 用几张 |
|---|---|
| 3 秒内 | 1 |
| 3–5 秒 | 2 |
| 5–8 秒 | 3 |
| 8 秒以上 | 3–4 |

写 `srcs` 时**多给几张**，让渲染器自动裁，不用自己数秒数。

### 同一支片子只能有一个"世界"

- 实拍 → 全部实拍（色温、年代可以不同，但都得是照片）
- 生成 → 全部生成，**同一个 style 参数**（`--style light`），同一套配色
- **不许混**：三张实拍 + 两张插画，观众会觉得是素材拼贴

## 三、层级

```
巨字（≥108px）    一屏最多一个，用来砸一个词
标题（44–52px）   一屏一个
正文（30–38px）   3～5 行
小字（22–26px）   说明、出处、单位
字幕（44–48px）   底部一行，独立于上面所有层级
```

规则：

- **字号跨度要大**：全片至少一次 ≥108px，也至少一次 ≤24px
- 一个镜头里**最多两个层级**（比如"巨字 + 小字说明"）
- 说明文字（`aside`）永远比正文小一档、颜色降一档

## 四、背景图（`bg`）

文字页加一张插画背景，压掉 PPT 白板感。

```json
{"type":"bullets","params":{"items":["…"],"bg":"assets/gen/g09.jpg"}}
```

- 强度固定在 **opacity 0.38**，高了抢文字
- 底部渐隐，保证字幕区干净
- 图层顺序：**底色 → 背景图 → 蒙版 → 内容**，靠 DOM 顺序，不要用负 z-index
- **不要**给 `.scene > *` 统一加 `z-index` 或 `position`——会破坏巨字/金句的绝对定位

---

## 五、常驻提纲（竖屏）

竖屏上半部是黄金位，放一棵常驻目录树。见 `03-镜头库.md` §0.6。

- 3–6 章，每章 0–4 小节
- 当前章节展开，讲完的打 ✓ 变灰，未讲到的压到 52%
- 片名卡 `noOutline: true`

## 六、检查表

交付前对一遍：

- [ ] 全片不超过 4 个颜色
- [ ] 渐变从 `var(--fg)` 起，不从白色起
- [ ] 图片来源统一（全实拍 or 全生成）
- [ ] 照片都肉眼确认过，`credit` 都填了
- [ ] 每个图片镜头 ≥ 2 张
- [ ] 至少一处巨字、一处小字
- [ ] 文字页都有 `bg`，不透白
- [ ] 竖屏有提纲，横屏没有
