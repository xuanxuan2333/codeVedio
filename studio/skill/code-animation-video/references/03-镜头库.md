# 03 · 镜头库（12 种）

所有镜头都是「入场动画 → 停留 → 淡出」，时长由配音自动决定。

> 配色、字号、留白都在 `kit/style.css` 的 `:root` 里，改主题只改那里。

---

## 0. 通用字段：`aside`（言外之意）

**每个镜头都可以带 `aside`**，渲染成画面右下角的一行蓝色小字（在字幕上方）。

作用：把旁白没说透的那句话，**明明白白写在屏幕上**。它不是字幕，是导演的补刀 / 判断 / 潜台词。

```json
{"type":"quote","say":"…","params":{
  "text":"法令：从今天起，所有人上街不许穿裤子。",
  "aside":"荒诞到不像真的，但逻辑是真的"}}
```

写法：

| 好 | 坏 |
|---|---|
| 短，一句，≤ 16 字 | 长句、带从句 |
| 是判断 / 吐槽 / 补充，不是复述 | 把旁白又说一遍 |
| 有态度（"听着粗暴，但这就是底层逻辑"） | 中性描述（"这是关于政治的说明"） |
| 一镜一句，不重复同一个意思 | 每个镜头都用同一句套话 |

**节奏**：不必每镜都写。建议 70%~100% 的镜头有，纯画面镜头（图片、视频）可以留空。

> 这条是「观点视频」和「说明视频」的分水岭：旁白负责讲清楚，`aside` 负责让人觉得你在**跟他想的一样**。

## 0.5 通用字段：`bg`（文字页的插画背景）

**任何文字类镜头都可以加 `bg`**，把一张插画铺成底图，压掉"PPT 白板感"。

```json
{"type":"bullets","params":{"title":"三个阶段","items":["…"],
  "bg":"assets/gen/g09.jpg"}}
```

规矩：

| | |
|---|---|
| 图片从哪来 | 用 `gen-image.mjs --style light` 生成的纸感插画，一张图可以反复用于多镜 |
| 强度 | 页面里固定在 `opacity: .38`，**不要调高**，高了会抢文字 |
| 蒙版 | 底部渐隐，保证字幕区干净 |
| 层级 | 背景层放在场景 DOM 的最前面，靠 DOM 顺序压在内容下（**不要用负 z-index，会掉到页面底下**） |
| 冲突 | 不要给 `.scene > *` 统一加 `z-index` / `position`——会破坏巨字、金句的绝对定位 |

> 这层是"质感"，不是"内容"。观众注意不到最好，注意到就过了。

## 0.6 顶部常驻提纲（竖屏专用）

竖屏上半部是黄金位。`meta.chapters` 会在那里渲染一棵常驻的目录树，标出当前讲到哪。

```json
"meta": {
  "chapters": [
    {"title": "政治是什么", "scenes": ["s2","s3","s4"]},
    {"title": "三个模板", "items": [
      {"label": "国家", "scenes": ["s7","s8","s9"]},
      {"label": "企业", "scenes": ["s11","s11b"]}
    ]}
  ]
}
```

效果：

- 已讲完的章节打 ✓、变灰
- 当前章节**展开**显示小节点，标题变强调色
- 当前小节前面亮一个点，讲完的小节变绿
- 未讲到的章节压到 52% 透明度

规则：

- **3–6 章**，每章 0–4 个小节；再多屏幕放不下
- 小节的 `scenes` 必须连续
- 片名卡加 `"noOutline": true`，开场和结尾留干净
- 只对竖屏生效；横屏隐藏

> 这条能治"听着听着走神"：观众随时能瞟一眼，知道自己在整条论证的哪一格。

## 1. `title` 片名卡
开场、结尾、章节标题。

| 参数 | 说明 |
|---|---|
| `kicker` | 左上角小字，英文大写最好看 |
| `title` | 主标题，≤ 12 字 |
| `sub` | 副标题，一句话 |
| `meta` | 底部小字 |

```json
{"type":"title","params":{"kicker":"AI HISTORY","title":"AI 发展史","sub":"七十年，几次起落","meta":"科普 · 科技史"}}
```

## 2. `bullets` 要点列表
「三点」「几个方面」。条目依次出现。

| 参数 | 说明 |
|---|---|
| `title` | 页标题 |
| `items` | 3–4 条，每条 ≤ 18 字，支持 `<em>关键词</em>` |

```json
{"type":"bullets","params":{"title":"三个阶段","items":["<em>符号主义</em>：把知识写成规则","<em>连接主义</em>：让机器自己学"]}}
```

## 3. `stat` 大数字
一个数字撑满屏，从 0 滚上去。

| 参数 | 说明 |
|---|---|
| `value` | 数字或短词 |
| `decimals` | 小数位 |
| `unit` | 单位（倍 / % / 年） |
| `label` | 这个数字是什么 |
| `note` | 脚注，**数据来源写这里** |

```json
{"type":"stat","params":{"value":1956,"unit":"年","label":"达特茅斯会议","note":"人工智能这个词，就在这里诞生"}}
```

> 数字必须是真数据；没出处写「示意」，或者别用这个镜头。

## 4. `quote` 金句
一屏一句话。引用、结论、转折。**不配图，让观众读。**

| 参数 | 说明 |
|---|---|
| `text` | 支持 `<br>` |
| `by` | 出处 |

```json
{"type":"quote","params":{"text":"钱烧完了，<br>就没人管了。","by":"AI 寒冬"}}
```

## 5. `image` 图片（单张 / 多张轮播）

| 参数 | 说明 |
|---|---|
| `src` | 单张图，`assets/x.png` |
| `srcs` | **多张图数组**；按镜头时长自动决定用几张（每张约 2.4 秒） |
| `caption` | 左下说明条，可空 |
| `kenburns` | `in` / `left` / `right`（多张时自动加推近） |
| `zoom` | 放大倍数，用来裁掉原图水印 |

```json
{"type":"image","params":{"srcs":["assets/court_1.jpg","assets/court_2.jpg","assets/court_3.jpg"],"caption":"让所有人遵守法律"}}
```

### 要几张？按这句话的长度算

**一句一张图会显得死板。** 括号里说「要一张法庭的图」，指的是**这个意思**，不是「一张」。

| 镜头时长 | 用几张 | 每张停留 |
|---|---|---|
| 3 秒以内 | 1 张 | — |
| 3–5 秒 | 2 张 | ~2 秒 |
| 5–8 秒 | 3 张 | ~2.5 秒 |
| 8 秒以上 | 3–4 张（有多少用多少） | ~2.4 秒 |

**渲染器会自动算**：`want = round(时长 / 2.4)`，上限是素材数量；素材多于所需时按均匀间隔挑。
所以写 `srcs` 时**多给几张（3–5 张）**，让它自动裁；不要自己数秒数。

取图：

```bash
node fetch-media.mjs "courtroom trial" assets/court.jpg --count 3
```

会产出 `court_1.jpg` / `court_2.jpg` / `court_3.jpg`，**每张都要亲眼看一遍**。

## 6. `video` 视频片段
播一段 B-roll，逐帧 seek（确定性）。

| 参数 | 说明 |
|---|---|
| `src` | `assets/x.mp4` |
| `start` | 从第几秒开始 |
| `loop` | 默认 true |
| `zoom` | 放大裁掉原片字幕 |

> ⚠️ 素材自带字幕会和你的字幕打架，优先 `zoom` 裁掉底部。

## 7. `compare` 左右对比
**最有用的一种镜头**：讲原理、讲改变、讲误解。

| 参数 | 说明 |
|---|---|
| `title` | 页标题 |
| `left.label` / `right.label` | 两栏标题 |
| `left.items` / `right.items` | 各 2–4 条 |

```json
{"type":"compare","params":{"title":"一条通道，还是两条","left":{"label":"只有文字","items":["符号→先在脑中翻译"]},"right":{"label":"画面 + 讲解","items":["直接看到结构"]}}}
```

## 8. `flow` 流程
横向步骤条，依次点亮。

| 参数 | 说明 |
|---|---|
| `title` | 页标题 |
| `steps` | 3–5 步，每步 ≤ 6 字 |
| `skip` | 要划掉的步骤下标，如 `[1]` |
| `note` | 下方小字 |

> `skip` 是灵魂：讲「省掉了哪一步」时把那步划掉，观众一眼就懂。

```json
{"type":"flow","params":{"title":"省掉的那一步","steps":["看到符号","脑中翻译","建立模型"],"skip":[1],"note":"画面直接跳到第三步"}}
```

## 9. `bars` 柱状图
数据对比。

| 参数 | 说明 |
|---|---|
| `title` | 页标题 |
| `data` | `[{name, value}]`，3–6 条 |
| `unit` | 数值后缀 |
| `max` | 纵轴上限 |

> 数据必须有出处。没出处的数据做成柱状图 = 造谣。

## 10. `code` 代码
窗口装饰 + 逐行高亮。

| 参数 | 说明 |
|---|---|
| `title` | 页标题 |
| `lang` | 右上角语言名 |
| `code` | 多行字符串 |
| `highlight` | 高亮行号数组 |

## 11. `person` 人物卡
左照片、右姓名/身份/一句说明。

| 参数 | 说明 |
|---|---|
| `name` | 姓名 |
| `role` | 身份 |
| `note` | 一句说明：他在这一段里的作用 |
| `photo` | 可选；没有就渲染成首字母卡 |
| `credit` | 照片署名，**用了照片必须填** |

```json
{"type":"person","params":{"name":"黄仁勋","role":"NVIDIA 创始人 & CEO","note":"台上发显卡，台下抢着买单。","photo":"assets/jensen.jpg","credit":"Photo: … / CC BY-SA · Wikimedia Commons"}}
```

**取照片：**

```bash
node fetch-media.mjs "黄仁勋" projects/<名字>/assets/jensen.jpg
```

下载后**必须亲眼看一遍**确认是本人。确认不了就删掉，用文字卡。

## 12. `brand` 品牌卡
默认是**文字 wordmark**（不抓 logo）。

| 参数 | 说明 |
|---|---|
| `name` | 品牌名 |
| `color` | 品牌色，如 `#76b900` |
| `note` | 一句话 |
| `logo` | 仅当用户提供素材时用 |

> 实测从 Commons 搜「Nvidia logo」拿到的是总部大楼照片。抓错的图比没有图更丢人。

---

## 选型速查

| 你要表达 | 用 |
|---|---|
| 开场/结尾/章节 | `title` |
| 并列的几点 | `bullets` |
| 一个数字、一个比例 | `stat` |
| 一句可独立成立的话 | `quote` |
| 有人名 | `person` |
| 有公司名 | `brand` |
| 两种东西不一样 | `compare` |
| 有先后、有因果 | `flow` |
| 有数据对比 | `bars` |
| 有代码 | `code` |
| 有现成图 / 视频 | `image` / `video` |

## 13. `kinetic` 动效文字（逐词弹入）

用于词云、巨字、"这个词才是重点"的爆点。比 `bullets` 更有冲击力，也不像 PPT。

| 参数 | 说明 |
|---|---|
| `words` | 词数组，3–8 个 |
| `highlight` | 高亮词的下标 |
| `sub` | 下方一行小字 |

```json
{"type":"kinetic","params":{"words":["战争","宗教","自由","民主","选举","独裁"],"highlight":5,"sub":"词很多，但没有一个是答案"}}
```

> 用在"列举/追问/反转"三个位置最有效。全片别超过 4 处，多了就成花架子。
