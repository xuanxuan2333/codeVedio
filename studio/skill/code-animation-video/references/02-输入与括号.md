# 02 · 输入与括号

## 格式

```markdown
一句口播。
（画面：片名卡 · 主标题「AI 发展史」，副标题「七十年，几次起落」）

下一句口播。
（画面：大数字 1956 年，下面一行「达特茅斯会议」）
```

| 规则 | 说明 |
|---|---|
| 一行口播 = 一次配音 | 逗号句号照读 |
| 一个 `（画面：…）` = 一个镜头 | 口播和括号成对，顺序不能乱 |
| 括号写「意图」，不写代码 | 写「左右对比」，不用写 `"type":"compare"` |
| 括号是自然语言 | 它要过你的翻译，不是给机器解析的 |

用户也可能**完全不写括号**，那就按 `04-编译规则.md` 自动配。

---

## 核心：括号在句尾，画面在句首

括号通常写在句子**末尾**，但它描述的画面要在**这句话开口的同时**出现。

```
声音： │────── 这句话 ──────│
画面： │── 就位 ────────────│
       ↑ 开口的同一刻，画面已经在动（0.3–0.6 秒内完全就位）
```

原因：观众先看见，再听懂。等说完再上图，图和话错开半拍，像 PPT 翻页。

**实现上天然满足**：一个镜头 = 一句配音，画面动画都从该镜 `t=0` 开始。
所以只要守住「一句一镜」，时机就是对的。

---

## 一句一镜

一句话一个画面。**一句话里塞了三件事、只挂一个括号，画面就接不住。**

反例：

> 最早是 1956 年达特茅斯会议，麦卡锡提出了这个词，然后经历了好几次寒冬（画面：大数字 1956）

观众听到「寒冬」时，屏上还停着 1956——画面比声音慢了一个信息点。

正例：

> 嗯，最早是 1956 年达特茅斯会议。（画面：大数字 1956）
>
> 然后是好几次寒冬，钱烧完了就没人管了。（画面：金句「钱烧完了，就没人管了」）

**注意：拆的是镜头，不是句子。** 原文一个字都没改，只是把一段话切成两句配音。

---

## 什么时候必须拆

| 症状 | 处理 |
|---|---|
| 一句超过 9 秒 | 拆成两镜（找一个自然的停顿点：逗号、分号、转折词） |
| 一句话里有 2 个以上信息点 | 拆，每个信息点一镜 |
| 括号只覆盖后半句 | 拆，让括号跟着它描述的那一句 |
| 用户一段话写了 3 个括号 | 按括号拆成 3 镜，句子切开 |

**切开后每段的 `say` 加起来，必须和原文完全一致**（标点可调，字不能丢）。

---

## 括号写得太糊怎么办

| 括号写法 | 处理 |
|---|---|
| `（画面：展示一下）` | 按 `04` 的决策树选一个最贴合的，交付时说明「这里我按 X 理解」 |
| `（画面：一个示意图）` | 同上；优先选能**演出来**的（`flow` / `compare`），不要静态图 |
| `（画面：放个视频）` | 没有素材就问用户要，或用 `quote` 顶上，**不要假装做了** |
| `（画面：转场）` | 本流程没有单独转场镜头，忽略，或用 `title` 做过渡 |
