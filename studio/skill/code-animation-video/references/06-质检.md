# 06 · 质检

交付前必须过一遍。**没过不要交片。**

---

## 一、遮住字幕三问

任取五镜，遮住字幕和所有小字，只留画面，问：

1. **这是什么？**（要用日常的词回答，不能是「一个抽象概念」）
2. **它在干什么？**（一个动词）
3. **我看明白了什么？**（一句话，说得出因果）

**答得含糊的镜头，就是没做好。** 回去改画面，不是回去加字幕。

---

## 二、五条硬指标

| 检查项 | 标准 |
|---|---|
| 镜头时长 | 单镜 3–9 秒；超过 12 秒且画面不动，拆 |
| 字幕 | 一屏一行，出现 0.2 秒内屏上要有动作 |
| 画面主体 | 任一时刻只有一个主体在动 |
| 素材 | 图 / 视频没有和字幕打架的烧录文字，没有水印 |
| 数据 | 每个数字有出处，没出处的标「示意」 |

---

## 三、文案侧

- [ ] 校对只动了三类（语病 / 错别字 / 事实错误）
- [ ] 口头禅还在（诶、那个、然后呢）
- [ ] 拆镜后每段 `say` 拼起来和原文一致，**一个字都没丢**
- [ ] 事实错误改过的，在交付里单独列出了

---

## 四、常见毛病

| 症状 | 病因 | 药 |
|---|---|---|
| 像 PPT | 全是 `bullets` + `title` | 插 `compare` / `flow` / `person` |
| 信息很多但记不住 | 一镜塞三件事 | 拆 |
| 听不懂 | 抽象词硬配抽象图 | 换具体形象，或只上字 |
| 节奏平 | 每镜一样长 | 长短交替 |
| 字幕和图打架 | 素材自带字幕 | `zoom` 裁掉 |
| 念错英文 | TTS 口音 | 词后加逗号 |

---

## 五、技术

- [ ] `--timeline` 没有超 12 秒的镜头
- [ ] 全片渲染无报错
- [ ] 成片有声音（`volumedetect` 的 `mean_volume` 在 -25 ~ -15 dB）
- [ ] 1920×1080 / 30fps

---

## 六、交付时说清楚

1. **校对清单**（没改就写「未改动」）
2. **我做了哪些判断**（"「寒冬」没有具体素材，用了金句镜头"）
3. **哪些没做到**（没拿到素材、某镜不太满意、没完整看片）
