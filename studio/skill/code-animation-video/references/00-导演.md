# 00 · 导演

**在写任何分镜之前，先当一次导演。**

排版员问"这句话配什么图"，导演问"这一分钟，观众的眼睛应该往哪走"。
没有这一层，片子就一定是 PPT：一句一屏、等宽字号、居中排版、每屏都在"列点"。

---

## 导演的交付物

两个文件，写在 `projects/<名字>/`：

| 文件 | 内容 | 谁来读 |
|---|---|---|
| `design.md` | 视觉纲领：一句话主张、母题、色/光、运动语言 | 所有下游 agent |
| `shots.md` | 逐镜设计表：镜号 / 视觉动作 / 画面层言外之意 / 举例 | 分镜 agent |

**没有 `design.md` 不许开工。** 否则每个分镜 agent 各画各的，拼起来一定散。

---

## 五个决定

### 1. 一句话视觉主张

全片只讲一个视觉念头。例：

- 「一个巨大的人影罩住一群一模一样的小人」→ 讲权力如何运作
- 「一根线被反复拉扯、快断」→ 讲张力/边界
- 「一层层剥开的洋葱」→ 讲复杂度

这句话决定了母题，**母题要反复回场**（至少 3 次，最后一次变化）。

### 2. 视觉母题（motif）

选**一个物件或形状**，全片反复用：人群、尺子、门、绳子、齿轮、地图……

- 第一次出现：建立（观众记住它）
- 中间出现：变形（换个角度/尺度）
- 结尾出现：反转（打破它）

> 没有母题 = 每屏都是新东西 = 观众记不住 = 像 PPT。

### 3. 色与光

- **3 色**：底色 / 主色 / 强调色。强调色全片只表达一件事（危险、结论、反例……）
- **一档对比**：要么通篇低对比（冷静），要么每 20 秒来一次高对比爆点
- 浅色底 ≠ 白底。用 `#f5f6f8` 这类带灰的底，纯白会"发飘"

### 4. 运动语言

全片只用 **2 种**镜头运动，选定就不要换：

| 运动 | 感觉 | 适合 |
|---|---|---|
| 推近（zoom in） | 逼视、强调 | 结论、反问 |
| 拉远（zoom out） | 抽离、看清全貌 | 举例之后收束 |
| 横移（pan） | 扫描、对比 | 列表、时间线 |
| 弹入（spring） | 轻快、有劲 | 数字、关键词 |

**同一镜只允许一个主体在动。**

### 5. 节奏曲线

把全片切成三段：

```
0–15%   钩子      高信息密度、快切、一次视觉冲击
15–85%  主体      每 20–30 秒一个"整屏画面"（满幅图/巨字/动效）
85–100% 收束      慢下来，母题回场，一句话收尾
```

---

## 「举例说明」：文案没写的，画面补

用户给你的文案往往只讲道理。**导演要负责补具体的例子**，而且必须在画面上**真的演出来**。

| 文案 | 导演补的例子 | 画面怎么做 |
|---|---|---|
| 「让人乖乖听话」 | 监狱、法庭、公司的打卡机 | 三张图连切，同一个构图 |
| 「拧成一股绳」 | 一群人拉同一根绳 | 矢量：多个小人 + 一根绳，方向一致 |
| 「代理人」 | 一只手在幕后操控木偶 | 生成一张夸张插画 |

规则：

- 例子**不改变原意**，只是把抽象换成具体
- 一个例子讲完就切走，不要停留
- 举例前留 0.3 秒停顿（用 `｜｜`），观众需要"准备听例子"的信号

## 「言外之意」的两层

### 文字层：`aside`

每个镜头的 `params.aside`，渲染成右下角一行蓝字。旁白没说透的判断写在这里。
见 `03-镜头库.md` 第 0 节。

### 画面层：让图自己说话

比 `aside` 更高级的做法——**画面里埋一个"不对劲"的细节**：

- 一群人整齐举手，**只有一个人没举**（讲"不是所有人都服从"）
- 金字塔顶端站着一个人，底下密密麻麻（讲"结构"）
- 巨大的法律文书压在一排小人身上（讲"规则的成本"）

写进 `shots.md` 的「画面层言外之意」一列。**一镜最多埋一个**，多了观众看不见。

## 反 PPT 检查表

交付前逐条对，任何一条不达标就返工：

| 检查 | 标准 |
|---|---|
| 整屏画面占比 | ≥ 1/3 的镜头是**满幅图 / 巨字 / 动效**，不是"标题+列表" |
| 连续同构 | 不允许连续 3 镜都是"左标题右列表"的版式 |
| 字号跨度 | 全片至少出现一次 ≥ 120px 的巨字，和一次 ≤ 24px 的小字 |
| 构图 | 至少 1/4 的镜头是**居中或满幅**，不是全部左对齐 |
| 运动 | 每个镜头都有入场动作；没有"静止出现"的镜头 |
| 停顿 | 每 20–30 秒有一处 ≥ 0.6 秒的停顿（`｜｜`），让眼睛休息 |
| 素材 | 图片镜头 ≥ 2 张轮播；不要一张图撑 8 秒 |

## 参考：网上教程里最有用的三条

1. **「配图不是讲解」**（[vibe-knowledge-film](https://github.com/HeyChengC/vibe-knowledge-film)）：
   把画面换到别的文案里照样成立 → 它是配图，不是讲解。
2. **「几何先于代数」**（Manim 社区）：先给形状，再给符号。观众先看见，才听得懂。
3. **「透明度分层引导注意力」**：主体 1.0，陪衬 0.4，结构（网格/坐标轴）0.15。
   全屏等亮度的片子，眼睛不知道看哪。
