# 为什么看动画比看文字好懂

同样一个知识点，做成动画，比写成文字，更容易被记住。
（画面：片名卡 · 主标题「为什么动画更好懂」，副标题「双通道编码，一次讲清」，右上角小字 CODE ANIMATION）

这不是感觉。同一份内容，配上画面和讲解，回忆的准确率大概能翻一倍。
（画面：大数字 2 倍，下面一行说明「画面 + 讲解 vs 只有文字」，右下角标注「数量级示意」）

原因主要有三条。
（画面：要点列表 · 标题「为什么更有效」，三条依次出现）

先说第一条：纯文字只有一条通道，大脑得自己把符号翻译成场景；而画面加讲解，是两条通道一起进。
（画面：左右对比 · 左边「只有文字」，右边「画面 + 讲解」，逐条出现）

举个例子。你看到「旋转」这两个字，和看到一个方块真的绕着角转起来，理解是同一条链路，但后者跳过了翻译那一步。
（画面：流程 · 三步「看到符号 → 脑中翻译 → 建立模型」，最后一行小字「画面直接从第一步跳到第三步」）

比如讲 transform，一个方块转一下，比一页文档说得还清楚。
（画面：视频片段 · 播放 demo-clip.mp4 的前几秒）

当然，动画不是万能的。信息密度太低，讲复杂结构反而更慢。
（画面：图片 · still.png，底部字幕条「同一帧里，位置、大小、角度三件事同时说清了」）

多媒体学习研究里有条原则：删掉无关的东西，比堆更多东西更有用。
（画面：金句 · 居中出现，出处写「多媒体学习研究 · 大意」）

所以真正该问的不是「要不要动画」，而是「这段内容里，有没有一个东西在动」。
（画面：要点列表 · 标题「一条判断标准」，三条）

下次写东西之前，先问自己一句。
（画面：片名卡 · 主标题「这里面，有什么在动？」，副标题「把答案画出来，就是一条科普片」）
